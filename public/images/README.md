# 画像の置き場所

写真をここに置くと、サイトに自動で反映される。
**写真が無い間は、セージグリーンのグラデが自動で表示される**（崩れない）。

## ファイル名（この名前で置けばOK）

| 置き場所 | ファイル | 推奨比率・サイズ |
|---|---|---|
| トップのヒーロー | `hero.jpg` | 縦長 4:5 / 1200×1500px 程度 |
| Aboutページ上部 | `about.jpg` | 横長 16:9 / 1600×900px |
| 活動カード・詳細 | `activities/taiwa-sanpo.jpg` | 横長 16:9 |
| 〃 | `activities/tetsugaku-taiwa.jpg` | 横長 16:9 |
| 〃 | `activities/dokushokai.jpg` | 横長 16:9 |
| 〃 | `activities/book-taiwa-bar.jpg` | 横長 16:9 |
| 〃 | `activities/zine.jpg` | 横長 16:9 |

- 拡張子は `.jpg` 固定（コード側がこの名前で参照している）
- 容量は1枚300KB以下を目安に圧縮しておくと表示が速い
- 顔がはっきり写る写真は、参加者の許可を取ってから使うこと
